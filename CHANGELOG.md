### Planned for v1.0.0

#### Added
- Round-based individual initiative system (D&D 5e, Pathfinder)
- Round-based side initiative system (OSR, AD&D)
- Pass-based initiative system with decay (Shadowrun 4/5)
- Slot-based initiative system (Genesys, FFG Star Wars)
- Popcorn initiative system (Marvel Heroic, Cortex)
- Dynamic actor management (add/remove mid-encounter)
- Initiative changes and delays with acted/unacted preservation
- Configurable tie-breaking rules (default: stable insertion order)
- Optional initiative bounds validation
- Configurable pass decay amount for Shadowrun editions
- Timeline profile validation
- Comprehensive PHPUnit test suite (90%+ coverage)
- PSR-12 code style compliance
- PHP 8.0+ compatibility
- Zero external dependencies (stdlib only)
- Complete API documentation
- Quickstart guide with RPG system examples
